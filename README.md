# PHILEdev Website

Premium PHILEdev technology and digital solutions website built with React, TypeScript, Vite, Tailwind CSS, Framer Motion and Lucide React.

## Included

- Home
- Work / Portfolio
- Individual project pages
- Currently Building
- Services
- About
- Process
- Contact / Start a Project
- Responsive navigation and layouts
- PHILEdev logo and founder imagery

## Completed projects

- FWL Travels & Tours
- Kaycee
- ZOBA ELITE SPA & MORE
- DRETA Cares

## In development

- EduTek
- Onje
- Rektify

## Run locally

```bash
npm install
npm run dev
```

## Production build

```bash
npm run build
```

The project is configured for Vercel. The `vercel.json` rewrite sends application routes to `index.html` so React Router works on direct navigation.
